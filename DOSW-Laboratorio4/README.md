- Story point estimation
i. En esta ocasión tuvimos principalmente un problema al estimar y es que no tenemos la experiencia de realizar las tareas designadas para las historias de usuario, por lo que no sabemos realmente cómo puntuar las tareas y demás, no tuvimos una métrica o estandarización que nos permitiera estimar de forma más real las tareas a realizar.

ii. Para nosotros fue realmente fácil llegar a un consenso ya que entendimos realmente el tiempo que toma, ya que a veces podemos estar cesgados, por lo que sirve contar con la discusión entre el equipo.

iii. Lo que hicimos fue utilizar el promedio de las cartas que utilizamos, o a veces exponemos nuestras ideas de cómo deberíamos de calificar una tarea y llegamos a un punto medio o a una calificación con la que todos estemos de acuerdo.
